# Evidencias

Aquí van las capturas de pantalla (y videos cortos, si hacen falta) de cada bug.

**Nombre de los archivos:** `BUG-001_modulo_que-falla.png`

Ejemplos de formato:

- `BUG-001_checkout_total-incorrecto.png`
- `BUG-002_catalogo_imagen-equivocada.png`

**Consejos**

- Toma la captura en el momento del fallo y que se vea la barra de direcciones del navegador.
- Si el fallo es una comparación, pon dos capturas: la de `standard_user` (correcta) y la del usuario con el problema.
- Para mostrar la captura dentro del reporte del bug, escribe: `![descripción](../evidencias/BUG-001_checkout_total-incorrecto.png)`
